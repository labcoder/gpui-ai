# First-party agent skills

These directories are the authored source for skills that teach agents how to
consume gpui-ai. They are part of the library's public guidance; installed
copies under an agent's own skill directory are not.

- [`gpui-ai`](gpui-ai/SKILL.md) — select, compose, style, and verify gpui-ai
  components in an application.

Copy or link the complete skill directory into the skill location supported by
your agent. Keep the directory intact so `SKILL.md` can load its references.
