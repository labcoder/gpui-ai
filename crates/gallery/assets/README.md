# Gallery assets

## carina-nebula.jpg

NASA/ESA/CSA/STScI — JWST NIRCam image of the "Cosmic Cliffs" in the Carina
Nebula, released 2022-07-12. Downloaded from NASA's image library
(`images-assets.nasa.gov/image/carina_nebula`) and resized to 640x370.

NASA content is generally not copyrighted and may be used without permission;
see <https://www.nasa.gov/nasa-brand-center/images-and-media/>. Kept here
because the decoration stories process a real photograph, and a synthetic
gradient does not have the tonal range that dithering and posterising are for.
